CO-OP MODE

PLAYER 2
CLAUDE CODE

Built together with an AI assistant, on my rules. CLAUDE.md and three project skills keep it on track: how scenarios are written, how page objects look and a step-by-step workflow for every new test.

Four Playwright test agents work in a chain: the planner explores a page and writes a plan, a reviewer on a stronger model checks it against the rules and the real page, the generator turns the approved plan into scenarios, and the healer fixes failing tests.
